# Security

Report a vulnerability privately through the contact form at https://greencyclepedia.com/#view=contact. Start the message with "Security" and include the address, what you sent and what came back. Please do not open a public issue for it.

The server is read only: no accounts, no keys, no cookies and no write operations. It answers at most 120 requests a minute per client. The privacy notice is at https://greencyclepedia.com/about/privacy/.

## Scope

- The MCP endpoint https://greencyclepedia.com/mcp and its server cards under https://greencyclepedia.com/.well-known/
- The open data files under https://greencyclepedia.com/api/
- The files in this repository

Text inside tool results that comes from papers, trials or feeds is marked as third party text. If you find a way to make the server return instructions that a model would follow as its own, that is in scope too.
